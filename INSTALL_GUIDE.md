# Fox Control — Инструкция по установке и обновлению

**Версия:** 1.0.0  
**Дата сборки:** 08.09.2026  
**Приложение:** Fox Control (com.andrew.foxcontrol)

---

## Что это за приложение

Fox Control — приложение родительского контроля, которое показывает, сколько времени ребёнок проводит за каждым приложением на смартфоне. При превышении установленных лимитов времени появляется предупреждение.

---

## Установка (первый раз)

### Шаг 1: Скачайте APK-файл

Получите файл `app-debug_1.0.0.apk` одним из способов:
- Через Telegram (отправьте файл)
- Через мессенджер WhatsApp
- По электронной почте
- Через облачное хранилище (Яндекс.Диск, Google Drive)
- Подключив телефон к компьютеру и скопировав файл

### Шаг 2: Разрешите установку из неизвестных источников

При первом открытии APK-файла телефон может попросить разрешение:

1. Нажмите **"Настройки"** в появившемся окне
2. Включите переключатель **"Разрешить установку из этого источника"** (или "Доверять этому источнику")
3. Нажмите **"Назад"**

### Шаг 3: Установите приложение

1. Откройте скачанный файл `app-debug_1.0.0.apk`
2. Нажмите **"Установить"**
3. Дождитесь окончания установки (несколько секунд)
4. Нажмите **"Готово"** или **"Открыть"**

### Шаг 4: Первоначальная настройка

При первом запуске приложение покажет экран приветствия. Следуйте инструкциям:

1. **Разрешение на использование** — нужно для отслеживания времени в приложениях
   - Нажмите "Открыть настройки"
   - Найдите Fox Control в списке и включите переключатель
   - Вернитесь в приложение

2. **Уведомления** — нужны для предупреждений
   - Нажмите "Открыть настройки уведомлений"
   - Включите уведомления
   - Вернитесь в приложение

3. **Автозапуск** — чтобы приложение работало в фоне
   - Нажмите "Разрешить автозапуск"
   - Включите переключатель
   - Вернитесь в приложение

4. **Батарея** — чтобы система не закрывало приложение
   - Нажмите "Отключить оптимизацию"
   - Выберите "Не оптимизировать"
   - Нажмите "Готово"

### Шаг 5: Установка пароля

После настройки разрешений:
1. Нажмите на иконку ⚙️ (Настройки) в правом верхнем углу
2. Введите имя пользователя (например, "Мама" или "Папа")
3. Перейдите в приватные настройки:
   - Нажмите на иконку 🔒
   - Введите пароль (по умолчанию: `12345`)
   - Установите новый пароль (введите дважды)
   - ⚠️ **Запомните пароль!** Без него доступ к настройкам невозможен

### Шаг 6: Настройка лимитов

В приватных настройках:
1. **Общий лимит** — максимальное время использования телефона в день (по умолчанию 2 часа)
2. **Лимиты для конкретных приложений** — можно установить лимит для каждого приложения отдельно

## Обновление (новая версия)

Когда вы получите новый APK-файл:

### Вариант 1: Обновление поверх старого (рекомендуется)

1. Скачайте новый APK-файл
2. Откройте его
3. Нажмите **"Обновить"**
4. Все данные сохранятся

### Вариант 2: Полная переустановка

⚠️ **ВНИМАНИЕ:** Этот способ удалит все данные!

1. Удалите старую версию
2. Установите новую версию
3. Настройте заново

## Важные советы

### 🔋 Батарея и фоновая работа

Чтобы приложение работало стабильно:

**Xiaomi / Redmi / POCO:**
- Настройки → Приложения → Приложения → Fox Control
- Батарея → Не оптимизировать
- Включите "Автозапуск"

**Samsung:**
- Настройки → Приложения → Fox Control
- Батарея → Неограниченный
- Включите "Автозапуск"

**Huawei / Honor:**
- Настройки → Приложения → Автозапуск → Включите Fox Control
- В недавних приложениях закрепите Fox Control (замок)

**Другие телефоны:**
- Настройки → Приложения → Fox Control
- Батарея → Не оптимизировать / Без ограничений

### 🔒 Безопасность

- Пароль по умолчанию: `12345`
- **Обязательно** измените пароль при первой настройке
- Не забывайте пароль — восстановить его невозможно
- Пароли хранятся в зашифрованном виде

### 📊 Как пользоваться

**Главный экран:**
- Сверху переключатель "Сегодня / Неделя"
- Показывается общее время использования
- Список приложений с временем

**Нажатие на приложение:**
- Показывает детальную статистику
- Можно установить индивидуальный лимит

**Настройки (⚙️):**
- Публичные: имя пользователя
- Приватные (🔒): пароли, лимиты, настройки отчётов

## Решение проблем

### Приложение не работает в фоне

1. Проверьте, что включён "Автозапуск"
2. Проверьте настройки батареи (см. выше)
3. Закрепите приложение в недавних (замок)
4. Перезагрузите телефон

### Не приходят уведомления

1. Настройки → Приложения → Fox Control → Уведомления
2. Убедитесь, что уведомления включены
3. Проверьте, что не включён режим "Не беспокоить"

### Приложения не отслеживаются

1. Настройки → Безопасность → Доступ к использованию
2. Найдите Fox Control и включите
3. Вернитесь в приложение

### Не могу войти в приватные настройки

- По умолчанию пароль: `12345`
- Если меняли и забыли — нужно переустановить приложение (данные пропадут)

### Приложение тормозит или работает медленно

1. Перезагрузите телефон
2. Проверьте, что осталось свободное место (минимум 1 ГБ)
3. Обновите приложение до последней версии
