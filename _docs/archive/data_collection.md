# Как работает сбор данных о запущенных приложениях

## Общая схема

Сбор данных работает через **foreground-сервис**, который запущен постоянно и использует два таймера (по 1 минуте каждый):

```
┌──────────────────────────────────────────┐
│  TrackingForegroundService               │
│  (работает всегда в фоне, виден как      │
│   уведомление "Мониторинг активен")       │
│                                          │
│  ┌─────────────┐  ┌────────────────────┐ │
│  │ Таймер 1     │  │ Таймер 2           │ │
│  │ HEARTBEAT    │  │ USAGE_STATS_POLL   │ │
│  │ 1 раз/мин    │  │ 1 раз/мин          │ │
│  └──────┬───────┘  └───────┬────────────┘ │
│         │                  │              │
│         ▼                  ▼              │
│   recordHeartbeat()   pollUsageStats()    │
│   (отметка "жив")    (сбор данных)        │
└──────────────────────────────────────────┘
```

## Запуск сервиса

1. При запуске приложения создаётся `TrackingForegroundService`
2. В `onCreate()` создаётся `TrackingJob` и запускается
3. Сервис становится **foreground** — показывает постоянное уведомление
4. Возвращается `START_STICKY` — если система убьёт сервис, она перезапустит его

## Два таймера

### Таймер 1: Heartbeat (сердцебиение)

- Запускается через `Timer.scheduleAtFixedRate()`
- Интервал: **60 000 мс (1 минута)**
- Действие: вызывает `usageStatsRepository.recordHeartbeat()`
- Цель: простая отметка, что сервис работает

### Таймер 2: Usage Stats Poll (сбор данных)

- Интервал: **60 000 мс (1 минута)**
- Действие: `pollUsageStats()` — основной метод сбора

## Как работает pollUsageStats()

Каждую минуту метод делает следующее:

### Шаг 1: Запрос к Android

```kotlin
val usageStatsList = usageStatsManager.queryUsageStats(
    INTERVAL_DAY,  // смотрим за день (для надёжности)
    startTime,     // 1 минуту назад
    endTime        // сейчас
)
```

Запрашиваем у `UsageStatsManager` статистику за последний промежуток времени.

### Шаг 2: Получаем список приложений

Android возвращает список всех приложений, которыми пользовались сегодня. У каждого — `totalTimeInForeground` (общее время на экране с начала дня).

### Шаг 3: Вычисляем дельту

```
Было:        Стало:         Разница:
1000 секунд → 1060 секунд → +60 секунд
```

Код хранит `lastForegroundTime[packageName]` — последнее известное значение времени для каждого приложения.

```kotlin
if (currentForeground >= previousTime) {
    // Обычный случай: время выросло
    deltaMs = currentForeground - previousTime
} else if (currentForeground < previousTime) {
    // Время пошло назад (приложение убито или ребут)
    deltaMs = 0
    // Сбрасываем треклинг
} else {
    // Первое появление приложения
    deltaMs = 0
}
```

### Шаг 4: Сохраняем сессию

Если `deltaMs > 0`, запускаем корутину и сохраняем в базу Room:

```kotlin
usageStatsRepository.trackUsageSession(
    packageName = packageName,
    appName = appName,
    startTime = endTime - deltaMs,
    endTime = endTime,
    durationMs = deltaMs,
    isEntertainment = false
)
```

### Шаг 5: Проверяем лимиты

После обработки всех приложений вызывается `alertManager.checkAndShowAlerts()` — проверяет, не превышены ли дневные лимиты. Если да — показывает overlay-уведомление.

## Обработка ошибок

### Время пошло назад

Бывает, когда:
- Приложение убила система
- Телефон перезагрузился
- Приложение зависло

Решение: сбрасываем треклинг, начинаем считать с нуля.

### Нет данных от UsageStats

Если `queryUsageStats()` вернул null/пустой список — логируем и выходим. Может быть, приложение не имеет разрешения на сбор UsageStats.

## Проверка разрешений

Отдельный мониторинг разрешений (`startPermissionMonitoring()`):

- Проверяет каждые 60 секунд
- Если потеряны критичные разрешения (usage stats или overlay) — перезапускает сервис
- Если потеряно только notification — просто логирует

## Логирование

Все события пишутся в `TrackingLogStorage`:

| Тег | За что отвечает |
|-----|----------------|
| `Service` | Foreground-сервис (создан, запущен, рестарт) |
| `Job` | TrackingJob (таймеры, опрос) |
| `Repo` | База данных (сессии, приложения) |
| `UsageStats` | Опрос UsageStatsManager (найдены приложения, время) |
| `Permission` | Проверка разрешений |
