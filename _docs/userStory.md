**User Story:** 
Проблема - Ребенок злоупотребляет временем за смартфоном. 
Нужно приложение для сбора статистики:      
- использования приложений (по часам-минутам, дням). 

**Общая информация:**
- приложение будет приватным (не будет публиковаться в google play) 
- рабочее название приложения - fox control
- с локальной базой данных 
- с возможностью выслать собщение на email (несколько емайлов)

**Базовый функционал:**
- приложение должно работать в фоне постоянно.
- если это возможно, фиксировать когда приложение fox control было выключено либо не работало.
- возможность мониторинга/отчетов в UI использования развлекательных приложений(игр, viber, ютуб и пр.) за сутки, или неделю.    
- возможность добавить суточный (00:00 - 23:59) лимит на общее время использования смартфона
- возможность добавить суточный (00:00 - 23:59) лимит на использование конкретного приложения 
- в случае если привышен лимит - выводить оповещение (поверх запущенных развлекательных приложений если возможно). 
- возможность отправки отчёта за сутки, на один или несколько e-mail. 
- 

**Модули**:
Приложение fox control, будет состоять из двух модулей. 

- главный модуль. При открытии приложения будет открываться главный модуль и будет показано статистика за сегодня. Также вверху должна быть добавлена возможность переключение просмотров - 2 вариантов просмотра статистики первый за сегодня, второй за неделю.
- настройки. Настройки будут разделены на две части первая публичная и приватная. Публичной части пользователь может поменять свою аватарку и редактировать имя. 
- приватных настройках (в приватной часть, можно попасть только введя пароль) : 
- можно будет добавить отредактировать общие лимит использования смартфонов за сутки. 
- суточный лимит использования каждого приложения. По умолчанию выводится список - топ 10 самых используемых приложений за неделю.
- можно будет добавить один или более емейлов для отправки отчётов. 
- можно будет отредактировать время отправки на e-mail суточного отчёта.
- поменять пароль в приватный раздел настроек.

Данные по умолчанию:
* при инициации приложения создается пользователь, имя по умолчанию - username
* По умолчанию пароль для доступа в приватные настройки 12345
* По умолчанию время отправки суточного отчёта на e-mail - 20:00 по кишинёвскому времени.

**Рекомендуемый стек:**

**Платформа:** Android  
**Язык:** Kotlin  
**UI:** Jetpack Compose + Material 3  
**Архитектура:** MVVM + Coroutines/Flow + Hilt + Room + Navigation Compose  
**Тип приложения:** Client-only (Offline-first). Бэкенд отсутствует. Все данные хранятся на устройстве.

### Паттерны:
- **MVVM** — Model-View-ViewModel
- **Clean Architecture** — разделение на data, domain, presentation
- **Hilt DI** — Dependency Injection
- **Room** — локальная база данных
- **Navigation Compose** — типобезопасная навигация
- **StateFlow** — реактивное управление состоянием
